# Mancer Mash

A card-combat game in Godot where the order of your cards and the state of an emotion queue shape the fight.

**Status:** In development · **Stack:** Godot, GDScript · **Source:** Private

## The project

Mancer Mash explores how sequencing can make a small set of cards produce different tactical choices. Work spans the combat system, enemy encounters, card presentation, animation, and the interface for understanding what happens next.

The game has separate implementation, design, and coordination records. Playtest decisions include revising and cutting designs, with an older prototype retained as part of the project's history.

## Areas of work

- Card sequencing and emotion-dependent combat behavior.
- Fight HUDs, ability slots, animation, and feedback.
- Design proposals, playtest records, and implementation decisions.
- Art direction, promotional experiments, and project coordination.

This is an ongoing independent project developed with AI-assisted workflows. There is no public playable release linked here yet.
