# Personal tools and experiments

Tools built around recurring problems in my own development and daily workflows.

## Desktop widgets

EWW panels and scripts for tasks, music, links, and personal workflows. The local project includes installation documentation and ongoing changes; a public repository destination is still being consolidated.

## Speech recognition evaluation

A small multilingual benchmark using eight recordings of my own speech. It compares transcription accuracy, mistakes in important phrases, latency, and resource use.

The choice involved a concrete tradeoff: a local medium model performed better on accuracy, while a hosted Groq option was selected for lower strain on the computer. These results describe a small, single-speaker sample. The recordings and personal transcripts are not published here.

## Assistant utilities

Local tools for collecting notes, maintaining project views, and organizing recurring work. These currently live in a mixed personal workspace rather than a standalone public package.

## Hermes customizations

Local changes to reminder delivery, Telegram behavior, and web extraction. These are customizations of an existing upstream project; they are not presented as merged upstream contributions.

## Unity experiments

Earlier Unity work includes a Platformer Microgame-based project and a sample-scene experiment. These are learning and prototyping projects with starter content, rather than finished original releases.
