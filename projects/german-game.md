# German Game

A browser-based 3D game for practicing German through exploration and everyday situations.

**Status:** Private playable learning experiment · **Stack:** React, TypeScript, Three.js, Rapier, Vinext, Cloudflare D1 · **Source:** Local, not yet published

## The project

Language tasks take place inside a navigable world. Players follow conversations, explore chapters, and complete market activities involving goods, quantities, budgets, listening, and deliveries.

The interface combines movement and physics with contextual objectives, journals, language support, and saved learning progress. Review activities distinguish guided practice from independent recall.

## Areas of work

- Browser-based 3D movement and interactions.
- Conversations and objectives connected to the game world.
- Market tasks with speech playback and recoverable mistakes.
- Checkpoints, saved history, and review activities.

The current build uses Sites hosting configuration and a D1 binding for persistence. The latest listening-market flow still needs hands-on audio and end-to-end playtesting. This is a learning experiment; no measured language-learning outcome is claimed.
